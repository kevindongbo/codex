## 四、必须遵守的业务规则

### 利润试算

- 删除利润计算页全部黄色说明框，统一迁移到“规则与说明”。
- 费用顺序：商品售价、平台代扣合计、商品采购成本、达人佣金、税费、物流费用、广告费用。
- 零金额项目仍显示。
- 平台代扣合计默认收起，整行和箭头都能展开/收起。
- 展开后只显示明细，不在底部重复显示小计或合计。
- 类目佣金调试显示为“类目佣金调试（按百分点临时调整）”，仅当前试算生效。

### TikTok Shop 马来西亚费用

- 交易手续费按当前官方规则：`(商品原价 - 商家折扣 + 买家支付运费 - 顾客订单退款金额) × 3.78%`。
- 不存在 RM4.13 封顶。
- 买家运费进入交易费基数，但不进入商品售价。
- 平台支持费按当前有效规则版本计算；默认 RM0.54/成功送达订单，支持豁免规则。
- 多 SKU 平台支持费按折后销售金额占比分摊，尾差给折后金额最高的 SKU。
- 类目佣金按类目、卖家类型、BXP、日期和有效版本读取。
- BXP 独立展示，不能与类目佣金合并。

### 规则管理

- 所有账号可查看，只有主账号持有者可修改、定时生效、取消计划和回滚。
- 权限必须后端校验。
- 修改原因必填，保存前二次确认。
- 支持立即生效和按北京时间所选日期 00:00 定时生效。
- 支持选择任意历史版本回滚；回滚生成新版本，不删除历史。

### 汇率

- 支持 CNY、MYR、USD 三币种相互兑换，使用市场中间价。
- 通过已配置且可联网搜索的 DeepSeek，每天北京时间 09:00 自动更新。
- 服务端必须校验来源、时间、正数、倒数关系、交叉汇率和异常波动。
- 所有登录账号可手动刷新。
- 只有主账号可手动修正；不需要原因和二次确认；手动值仅当天有效。
- 前端不提供汇率历史入口，但后台保留日志。

### 仓间调拨

- 状态：草稿、调拨在途、部分调入、已调入、已取消。
- 进行中只包括调拨在途和部分调入，不包括草稿。
- 草稿仅在全部中显示，可编辑和删除，不扣库存。
- 正式发出后调出仓固定；草稿和进行中可修改调入仓。
- 调拨在途可新增、删除商品并增减数量。
- 支持按 SKU 多次部分收货。
- 每次收货记录可单独撤回。
- 撤回时库存不足必须禁止，不能产生负库存。
- 部分收货后只可编辑剩余在途部分；已收货数量需先撤回才能改。
- 所有库存变化必须使用数据库事务、库存流水和审计记录。
- 所有发出、收货、撤回、取消接口必须幂等。

### 智能补货

- 默认权重：3 天 40%、7 天 30%、15 天 20%、30 天 10%。
- 总和不等于 100% 禁止保存。
- 全局修改仅覆盖当前仓库全部有效 SKU，并覆盖旧的单独权重；必须二次确认。
- 可勾选一个或多个 SKU 单独批量修改。
- 全选必须选择当前仓库全部有效 SKU，不受筛选和分页影响。
- 未选中 SKU 时重新计算全部；有选中时只计算所选。
- 删除“信心度”展示。
- 周期明细、补货参数和计算依据默认收起。

### 登录刷新

- 用户只要求同一标签页 F5 刷新不退出，不要求关闭浏览器后持续登录。
- 优先修复现有 `sessionStorage + refresh token` 恢复流程。
- 临时断网、500、超时不得无提示清空会话。
- 只有 refresh token 失效、账号停用、后端明确拒绝或主动退出时才返回登录页。
