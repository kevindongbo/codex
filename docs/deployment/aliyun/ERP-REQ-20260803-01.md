# ERP-REQ-20260803-01 阿里云部署命令

部署目标：`codex/erp-req-20260803-integration` 的已测试提交
`3e3572c3d747bb8670203de52f6ef5346ea00d1e`。命令基于仓库
`DEPLOYMENT_ERP_OPERATIONS.md`：`/opt/dongbo/app`、`/opt/dongbo/venv`、
`dongbo-erp`、Nginx 和 `dongbo_erp`。不会打印 `.env` 内容。

本次包含迁移 `0025_stocktransfer_partial_receipts`。正式部署会在迁移前备份
当前代码提交和 PostgreSQL；未在本次工作中执行生产部署。

## 正式部署

```bash
set -euo pipefail
APP=/opt/dongbo/app
VENV=/opt/dongbo/venv
BRANCH=codex/erp-req-20260803-integration
SHA=3e3572c3d747bb8670203de52f6ef5346ea00d1e
cd "$APP"
REMOTE=$(git remote | while read -r name; do url=$(git remote get-url "$name"); case "$url" in *github.com/kevindongbo/codex*) printf '%s\n' "$name"; break;; esac; done)
test -n "$REMOTE"
test -z "$(git status --porcelain)"
git fetch "$REMOTE" "$BRANCH"
git cat-file -e "$SHA^{commit}"
git merge-base --is-ancestor "$SHA" "$REMOTE/$BRANCH"
STAMP=$(date +%Y%m%d-%H%M%S)
BACKUP_DIR=/opt/dongbo/backups/$STAMP
sudo mkdir -p "$BACKUP_DIR"
git rev-parse HEAD | sudo tee "$BACKUP_DIR/code-commit.txt" >/dev/null
sudo tar --exclude=.git --exclude=.venv --exclude=.env -C /opt/dongbo -czf "$BACKUP_DIR/app.tar.gz" app
sudo -u postgres pg_dump -Fc dongbo_erp > "/tmp/dongbo_erp-$STAMP.dump"
sudo mv "/tmp/dongbo_erp-$STAMP.dump" "$BACKUP_DIR/dongbo_erp.dump"
git checkout --detach "$SHA"
"$VENV/bin/pip" install -r backend/requirements.txt
set -a
. "$APP/.env"
set +a
cd "$APP/backend"
"$VENV/bin/python" manage.py migrate
"$VENV/bin/python" manage.py collectstatic --noinput
sudo systemctl restart dongbo-erp
sudo nginx -t
sudo systemctl reload nginx
sudo systemctl is-active --quiet dongbo-erp
curl -fsS http://127.0.0.1:8000/api/health/
printf '部署完成。备份目录：%s\n' "$BACKUP_DIR"
```

## 一键回滚

> 该命令会将 PostgreSQL 恢复到部署前备份，部署后新增数据会丢失。请只在确认需要回滚时执行，并输入正式部署输出的 `BACKUP_DIR`。

```bash
set -euo pipefail
APP=/opt/dongbo/app
VENV=/opt/dongbo/venv
read -r -p '输入正式部署输出的 BACKUP_DIR: ' BACKUP_DIR
test -f "$BACKUP_DIR/code-commit.txt"
test -f "$BACKUP_DIR/dongbo_erp.dump"
PREVIOUS_SHA=$(cat "$BACKUP_DIR/code-commit.txt")
cd "$APP"
git cat-file -e "$PREVIOUS_SHA^{commit}"
sudo systemctl stop dongbo-erp
sudo -u postgres pg_restore --clean --if-exists --no-owner -d dongbo_erp "$BACKUP_DIR/dongbo_erp.dump"
git checkout --detach "$PREVIOUS_SHA"
set -a
. "$APP/.env"
set +a
cd "$APP/backend"
"$VENV/bin/python" manage.py collectstatic --noinput
sudo systemctl start dongbo-erp
sudo nginx -t
sudo systemctl reload nginx
sudo systemctl is-active --quiet dongbo-erp
curl -fsS http://127.0.0.1:8000/api/health/
sudo journalctl -u dongbo-erp -n 100 --no-pager
printf '已回滚到 %s，并从备份恢复数据库。\n' "$PREVIOUS_SHA"
```
