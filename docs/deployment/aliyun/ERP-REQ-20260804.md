# ERP-REQ-20260804 阿里云部署、验证与回滚

部署目标为分支 `codex/implement-erp-requirements-20260804` 中已完成全量测试的代码提交
`6cd43fe71107cf9a280c2b5929e5c25201d0ff80`。服务器参数依据仓库现有
`DEPLOYMENT_ERP_OPERATIONS.md` 和 `docs/deployment/aliyun/ERP-REQ-20260803-01.md`：
应用目录 `/opt/dongbo/app`、虚拟环境 `/opt/dongbo/venv`、Django systemd 服务
`dongbo-erp`、PostgreSQL 数据库 `dongbo_erp`，Nginx 使用服务器现有配置。

本次包含迁移 `0026_stores_competitors_exchange_rates`，会增加自有店铺、SKU 店铺商品、
竞品店铺分组及历史、汇率快照，并补充 SKU 利润字段和全系统唯一编码约束。正式部署在
迁移前备份代码、数据库和可能存在的同名汇率 systemd 单元。下面命令不会打印 `.env`
内容。本文件只是部署操作手册；生成文档时未在生产服务器执行这些命令。

每日汇率刷新默认使用 `Asia/Shanghai` 09:00，附带最多 120 秒随机延迟。若以后需要调整，
应使用 `systemctl edit dongbo-exchange-rates.timer` 覆盖 `OnCalendar`，然后执行
`systemctl daemon-reload` 和重启该 timer，不要直接改仓库中的基准单元文件。

## 1. 正式部署命令

```bash
set -euo pipefail
APP=/opt/dongbo/app
VENV=/opt/dongbo/venv
BRANCH=codex/implement-erp-requirements-20260804
SHA=6cd43fe71107cf9a280c2b5929e5c25201d0ff80
DB_NAME=dongbo_erp
APP_SERVICE=dongbo-erp
RATE_SERVICE=dongbo-exchange-rates.service
RATE_TIMER=dongbo-exchange-rates.timer
cd "$APP"
REMOTE=$(git remote | while read -r name; do url=$(git remote get-url "$name"); case "$url" in *github.com/kevindongbo/codex*) printf '%s\n' "$name"; break;; esac; done)
test -n "$REMOTE"
test -z "$(git status --porcelain)"
git fetch "$REMOTE" "$BRANCH"
git cat-file -e "$SHA^{commit}"
test "$(git rev-parse "$SHA")" = "$SHA"
git merge-base --is-ancestor "$SHA" "$REMOTE/$BRANCH"
STAMP=$(date +%Y%m%d-%H%M%S)
BACKUP_DIR=/opt/dongbo/backups/$STAMP
sudo mkdir -p "$BACKUP_DIR/systemd"
git rev-parse HEAD | sudo tee "$BACKUP_DIR/code-commit.txt" >/dev/null
sudo tar --exclude=.git --exclude=.venv --exclude=.env -C /opt/dongbo -czf "$BACKUP_DIR/app.tar.gz" app
sudo -u postgres pg_dump -Fc "$DB_NAME" > "/tmp/${DB_NAME}-${STAMP}.dump"
sudo mv "/tmp/${DB_NAME}-${STAMP}.dump" "$BACKUP_DIR/${DB_NAME}.dump"
for UNIT in "$RATE_SERVICE" "$RATE_TIMER"; do
  if sudo test -f "/etc/systemd/system/$UNIT"; then
    sudo cp -a "/etc/systemd/system/$UNIT" "$BACKUP_DIR/systemd/$UNIT"
  fi
done
if sudo systemctl is-enabled --quiet "$RATE_TIMER"; then
  printf 'enabled\n' | sudo tee "$BACKUP_DIR/rate-timer-state.txt" >/dev/null
else
  printf 'disabled\n' | sudo tee "$BACKUP_DIR/rate-timer-state.txt" >/dev/null
fi
git checkout --detach "$SHA"
test "$(git rev-parse HEAD)" = "$SHA"
"$VENV/bin/pip" install -r "$APP/backend/requirements.txt"
set -a
. "$APP/.env"
set +a
cd "$APP/backend"
"$VENV/bin/python" manage.py migrate --noinput
"$VENV/bin/python" manage.py collectstatic --noinput
sudo install -m 0644 "$APP/backend/scripts/$RATE_SERVICE" "/etc/systemd/system/$RATE_SERVICE"
sudo install -m 0644 "$APP/backend/scripts/$RATE_TIMER" "/etc/systemd/system/$RATE_TIMER"
sudo systemctl daemon-reload
sudo systemctl enable --now "$RATE_TIMER"
sudo systemctl restart "$APP_SERVICE"
sudo nginx -t
sudo systemctl reload nginx
sudo systemctl is-active --quiet "$APP_SERVICE"
sudo systemctl is-active --quiet "$RATE_TIMER"
"$VENV/bin/python" manage.py showmigrations erp | grep -F '[X] 0026_stores_competitors_exchange_rates'
curl -fsS --max-time 15 http://127.0.0.1:8000/api/health/
printf '\nDEPLOY_SUCCESS SHA=%s\nBACKUP_DIR=%s\n' "$SHA" "$BACKUP_DIR"
```

## 3. 一键回滚命令

恢复 PostgreSQL 备份会删除部署后新写入的数据。执行者必须输入正式部署输出的
`BACKUP_DIR`，并再次输入 `ROLLBACK` 确认。代码归档保留在同一备份目录，下面命令使用
备份中记录的精确旧提交恢复代码，并恢复部署前数据库和汇率 timer 状态。

```bash
set -euo pipefail
APP=/opt/dongbo/app
VENV=/opt/dongbo/venv
DB_NAME=dongbo_erp
APP_SERVICE=dongbo-erp
RATE_SERVICE=dongbo-exchange-rates.service
RATE_TIMER=dongbo-exchange-rates.timer
read -r -p '输入正式部署输出的 BACKUP_DIR: ' BACKUP_DIR
case "$BACKUP_DIR" in /opt/dongbo/backups/*) ;; *) printf '备份目录不合法\n' >&2; exit 1;; esac
test -f "$BACKUP_DIR/code-commit.txt"
test -f "$BACKUP_DIR/${DB_NAME}.dump"
test -f "$BACKUP_DIR/app.tar.gz"
read -r -p '恢复数据库会丢失部署后的新增数据；输入 ROLLBACK 继续: ' CONFIRM
test "$CONFIRM" = ROLLBACK
PREVIOUS_SHA=$(tr -d '[:space:]' < "$BACKUP_DIR/code-commit.txt")
cd "$APP"
git cat-file -e "$PREVIOUS_SHA^{commit}"
sudo systemctl disable --now "$RATE_TIMER" 2>/dev/null || true
sudo systemctl stop "$APP_SERVICE"
sudo -u postgres pg_restore --clean --if-exists --no-owner -d "$DB_NAME" "$BACKUP_DIR/${DB_NAME}.dump"
git checkout --detach "$PREVIOUS_SHA"
test "$(git rev-parse HEAD)" = "$PREVIOUS_SHA"
"$VENV/bin/pip" install -r "$APP/backend/requirements.txt"
for UNIT in "$RATE_SERVICE" "$RATE_TIMER"; do
  if sudo test -f "$BACKUP_DIR/systemd/$UNIT"; then
    sudo install -m 0644 "$BACKUP_DIR/systemd/$UNIT" "/etc/systemd/system/$UNIT"
  else
    sudo rm -f "/etc/systemd/system/$UNIT"
  fi
done
sudo systemctl daemon-reload
if sudo test -f "$BACKUP_DIR/rate-timer-state.txt" && grep -qx enabled "$BACKUP_DIR/rate-timer-state.txt"; then
  sudo systemctl enable --now "$RATE_TIMER"
fi
set -a
. "$APP/.env"
set +a
cd "$APP/backend"
"$VENV/bin/python" manage.py collectstatic --noinput
sudo systemctl start "$APP_SERVICE"
sudo nginx -t
sudo systemctl reload nginx
sudo systemctl is-active --quiet "$APP_SERVICE"
curl -fsS --max-time 15 http://127.0.0.1:8000/api/health/
sudo journalctl -u "$APP_SERVICE" -n 100 --no-pager
printf '\nROLLBACK_SUCCESS SHA=%s DATABASE_BACKUP=%s\n' "$PREVIOUS_SHA" "$BACKUP_DIR/${DB_NAME}.dump"
```
