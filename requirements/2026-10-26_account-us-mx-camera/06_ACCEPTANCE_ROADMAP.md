# 验收标准、实施路线与交付门禁

本文件中的用例是**后续必须实现的验收标准**，不是本轮已经执行的功能测试。本轮仅文档审计、引用／结构及数值样例检查。

| AC-A12 | 桌面/手机搜索、筛选、归档弹窗取消/确认、恢复 | 四组列表和数量一致；取消零写入；焦点可达；390px无整页横滚；原因不对普通成员可见 |

| 编号 | 前置与操作 | 预期 |
| --- | --- | --- |
| AC-F01 | US当前有效摄像头佣金组，含买家运费和平台折扣 | 使用S-US-01适用基数；税剔除一次；买家运费即使非商家收入也可进入佣金基数 |
| AC-F02 | MX普通成交且已核验固定费适用粒度 | 平台佣金与每件MXN6分行，不只显示佣金；数量、同SKU多件和多个SKU有核验样例 |
| AC-F03 | MX SFP加入/退出、封顶前后、补贴未知 | 服务费独立；按有效版本封顶；未知补贴不自动抵扣；SFP不冒充仓储履约 |
| AC-F04 | US新商优惠、MX优惠到期或额度用尽 | 仅匹配资格时减佣；到期恢复标准；不能错误减免MX售出固定费 |
| AC-F05 | 原价、商家折扣、平台折扣、退款 | 各自按规则影响费基，平台补贴不会加两次；退款按单独规则而非简单负数订单 |

| AC-F07 | FBT小件实重例外阈值内外；Standard同尺寸 | 按各服务独立规则，结果可不同；不全局固定139或166 |
| AC-F08 | 两个SKU合一个包裹、同SKU两件、拆两包裹 | 运费依包裹收取；每件费依件收取；FBT等按服务粒度；分摊之和与订单总数一致 |
| AC-F09 | 修改重量、尺寸、地区、service后复用旧quote | hash不匹配被拒绝，重新报价；无目的地不得当Zone1 |
| AC-F10 | MX30kg边界及US服务尺寸/重量上限 | 按该版本上限及包裹限制处理；超过不外推；不能统一沿用MY30000g |
| AC-F11 | US旺季起止、跨太平洋/中国日期、LIVE与非LIVE | 使用as_of对应有效时区与版本；未来规则不提前生效；CBT/Standard不误用同一调整 |
| AC-F12 | 头程已在落地成本、FBT已含拣包尾程 | 明细标已包含，不重复扣；商家人工确认0有来源且不等同缺失 |
| AC-F13 | US代收销售税、MX价内税/代扣/服务费含税 | 回款与利润按资金流和税务口径分别展示；同税不双扣；RFC资料缺失不给无依据净利 |
| AC-F14 | 广告数据留空，实际CPA/ROI/占比分别输入 | 留空只出广告前毛利；有广告才出经营净利；ROI口径一致，G<=0保本ROI=null |
| AC-F15 | US/MX成本CNY及USD广告费用，汇率过期或不全 | 使用同一rate_set且方向正确；USD/USD=1；缺汇率拒绝完整结果，不用MY汇率 |
| AC-F16 | 计算后费率/税务/报价/汇率更新，再保存 | context_changed 409要求重算；同context算与存一致；旧版本回读不被当前规则重算 |

## 4. 可手算的测试向量

除注明官方规则的费率外，下面金额均为**合成测试夹具**，不构成物流报价或真实税务结论。实现时固定所有费用来源和舍入方式。

### N-01：美国单摄像头完整经营测算

商品税外售价USD100，无退款、折扣和买家运费；平台佣金6%，已确认达人费10%；采购CNY140、头程CNY21，测试汇率CNY/USD=7；当地自发货人工确认USD8且线下支付；其余已核验无额外费用，销售税为平台过手项。

```text
采购成本 = 140 / 7 = USD20
头程成本 = 21 / 7 = USD3
平台佣金 = 100 × 6% = USD6
达人费 = USD10
广告前毛利 = 100 - 20 - 3 - 8 - 6 - 10 = USD53
毛利率 = 53.00%
保本ROI = 100 / 53 = 1.89（展示2位）
保本CPA = USD53
未填广告：经营净利润=null；填CPA USD10：净利润USD43，净利率43.00%
预计平台回款 = 100 - 6 - 10 = USD84（不扣线下支付的采购/头程/尾程）
```

若同一USD8改为平台扣取的面单费，利润仍为USD53，平台回款改为USD76。此用例专门防止“回款＝毛利＋采购成本”的错误捷径。

### N-02：美国佣金基数

商品税外100、平台折扣5、买家运费10、checkout销售税8，则客户支付113。S-US-01当前费率6%时，费基`113+5-8=110`，佣金USD6.60。商家是否保留运费收入由资金流另判，不改变该佣金基数。

### N-03：墨西哥收费组件

测试单件商品1000 MXN，无折扣、退款或买家运费，且对应店铺符合已核验普通佣金及SFP规则：平台佣金60、售出固定费6、SFP服务费`min(1000×8%,40)=40`，三个组件合计MXN106。**这不是最终利润**，税务、达人、商品及物流仍需继续扣算；不能把106当作含全部税费的总成本。

低价测试商品300 MXN时SFP服务费24；新商若有效0佣金优惠适用，仍需保留其他适用固定费与计划费。数量两件及退款边界另由官方样例准入，不能仅凭本向量推断。

### N-04：单位与服务差异

2lb=907.18474g，332in³为FBT该版本小件门槛之一；边界按未截断数值判断。Standard的示例包裹16×12×10in、实重5lb，按139的体积重约13.813lb；最终进位由Standard有效价表决定，不能直接拿此未进位值取价格。另一服务用166或小件例外时单独比较，不能覆盖Standard规则。

### N-05：订单分摊

同包裹内商品税外金额30和70，共付尾程10，本地分摊3和7；两件售价相同且订单费用0.01时按稳定item顺序分到0.01和0.00，总额仍0.01。显示分摊不能改变平台实际按件收固定费或按包裹收物流费的账务粒度。

## 6. 测试分层与回归

- 后端：账号权限/JWT/并发/幂等；费用Decimal和数量；物流边界/地区/日期；国家隔离；快照重算一致；外部失败错误码。
- PostgreSQL：真实行锁、约束、批量原子性、回填幂等；真实旧schema→新schema、数据hash/数量/金额校验；不能只在SQLite证明可迁移。
- 前端：国家切换和迟到响应、未保存草稿、401刷新、403权限、明示0、类目错国、报价失效；不写仅镜像实现的低价值测试。
- 浏览器：1366/1440/1920以及390/430；账号归档/恢复、三国切换、摄像头分类、费用明细、保存/刷新/历史；pageerror/console.error为0，键盘及弹窗焦点可用。
- 保护回归：采购收货、库存流水和数量、原店铺MY售价保存、原MY公式/汇率、利润版本不可改、角色权限、原图隐私、排班历史及人工调整。不能删除原测试来适应新行为。
- 官方数据：每个published物流／费率版本至少正常、边界、超范围、缺资料各一组；混合订单及同SKU多数量样例必测；官方金额不能以模型生成数据替代。

## 8. 风险与发布约束

1. 官方政策会变化，公开图表不完整，US各服务重量除数不同；以服务版本准入，不发布“全球统一费率”。
2. MX税务和物流资格未核验；开发可先完成能力骨架，正式完整结果需对应资料，不能承诺所有组合首日可用。
3. User删除会破坏或被外键阻止；本期归档不触碰业务历史，恢复不得复活旧token。
4. 多国金额最危险的失败是“数值不变、币种改了”；后端币种校验、旧字段MY限制与不可变快照必须优先。
5. v1-MY和新v2并存时禁止偷偷换公式；界面缓存版本要随静态资源变化，避免重现旧英文状态页面。
6. 上一轮课表queued和周日／界面需求不属于本需求包的完成声明；本轮没有实现或验收它们。

每批提交需写：目标／实际行为、改动范围、迁移及回滚、实际测试输出、未核验项、精确SHA。默认Draft PR，不自动合并main。上线要在备份和可回滚条件下按用户当次授权执行；仅文档上传不能表示已部署。
