## 3. 总体原则

1. 本页面是利润预测工具，不持续接收真实结算单，不实现实际手续费覆盖预测值。
2. 真实 TikTok Malaysia 结算单只用于验证公式和四舍五入。
3. 所有核心公式在后端统一计算，前端只提交参数和展示后端结果。
4. MYR 是计算本位币；CNY 用于展示和人民币采购成本换算；USD 只用于 CPA 等明确的美元指标。
5. 财务计算必须使用 Decimal，最终金额按 MYR 分位四舍五入。

## 4. 买家支付运费

### 4.1 计算配置

在“计算配置”增加：

- `买家是否支付运费`开关；
- `买家配送区域`：西马、东马；开关开启时可用，默认西马；
- 当前渠道固定为 Standard，代码结构允许以后增加渠道；
- `官方交易手续费率`只读；
- `交易手续费率调整`，单位为百分点，可正可负；
- `调整后交易手续费率`只读。

开关名称必须是“买家是否支付运费”。费率字段必须叫“交易手续费率调整”，不要使用“实际使用费率”。

### 4.2 Standard 买家运费规则

| 区域 | 买家支付运费 |
|---|---:|
| 西马 | RM2.90 |
| 东马 | RM8.00 |

规则：

- 开关关闭：买家支付运费 RM0.00；
- 开关开启：按区域自动取值，不再在费用明细手工填写；
- 默认西马；
- 买家运费是一次测算/订单级金额，只加入一次，不能随 SKU 行数重复；
- 本土发货不套用跨境 Standard 规则，返回 RM0，并可禁用区域控件。

### 4.3 跨境物流口径

跨境段物流成本继续使用现有价表：

```text
跨境段物流成本 = ceil(包装后重量 ÷ 10g) × RM0.15
```

真实结算关系：

```text
平台显示的实际运费 = 跨境段物流成本 + 买家支付运费
净物流成本 = 平台显示的实际运费 - 买家支付运费
```

因此利润预测中真正扣减的物流成本等于跨境段物流成本。

费用明细中：

- 保留物流归类；
- `商家运费（系统估算）`可以改为`净物流成本（系统估算）`；
- `买家支付运费（系统预测）`作为参考项展示，不允许编辑；
- 物流分组合计只等于净物流成本；
- 不新增重复的右侧逐项汇总行。

## 5. 交易手续费

```text
调整后交易手续费率
= max(0, 官方交易手续费率 + 交易手续费率调整)
```

`+0.20`表示增加 0.20 个百分点，例如 3.78% → 3.98%；不是乘法调整。

```text
交易手续费计费基数
= 商品销售收入合计
+ 买家支付运费
- 与交易手续费相关的客户退款
```

```text
预测交易手续费
= 交易手续费计费基数 × 调整后交易手续费率
```

示例：

```text
商品售价 RM16.99
西马买家运费 RM2.90
费率 3.78%
计费基数 RM19.89
交易手续费 RM0.75
```

后端结果必须返回官方费率、调整百分点、最终费率、计费基数和手续费金额，便于审计。

## 7. LVG 商品税

最终规则：

- 跨境发货且单件商品售价 `<= RM500.00`：售价视为已含 LVG 10%；
- 单件商品售价 `> RM500.00`：不自动套用 LVG 10%，状态显示“超出 LVG 范围”；
- 本土发货：LVG 为 RM0.00。

```text
LVG 税额 = 含税售价 × 10 / 110
```

本轮以真实结算单的 SST/LVG 扣费结构为准：

- LVG 不重复加入收入；
- LVG 进入平台结算费用、总费用、广告前总成本和广告后总成本；
- 达人佣金基数继续使用`含税售价 - 自动拆分的 LVG 税额`；
- 左侧费用明细保留 LVG 行和规则来源；
- 删除“LVG 仅展示、不计成本”的旧说明、旧返回语义和旧测试。

必须覆盖 RM500.00 与 RM500.01 边界测试。

## 8. 金额与利润公式

### 8.1 总收入

```text
总收入 = 商品销售收入合计
```

买家支付运费不计入总收入。

### 8.2 总费用

```text
总费用
= 平台类目佣金
+ 交易手续费
+ BXP/其他平台服务费
+ 平台支持费
+ 达人推广佣金
+ LVG 商品税
+ 净物流成本
+ 其他平台结算费用
```

总费用不含商品采购成本和广告费用。

### 8.3 总结算金额

```text
总结算金额 = 总收入 - 总费用
```

### 8.4 广告前

```text
广告前总成本合计
= 总费用 + 商品采购成本 + 其他非广告经营成本

广告前毛利
= 总收入 - 广告前总成本合计

毛利率
= 广告前毛利 ÷ 商品销售收入合计
```

### 8.5 广告后

```text
广告后总成本合计
= 广告前总成本合计 + 广告费用

净利润
= 总收入 - 广告后总成本合计

利润率
= 净利润 ÷ 商品销售收入合计
```

未填写有效广告数据时：

- 广告前数据正常计算；
- 广告后总成本、净利润、利润率返回 null，并显示“未计算”，不能显示 0。
